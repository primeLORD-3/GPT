# Proxy Chat Studio 使用文档

## 1）运行

```bash
npm install
npm start
```

访问：`http://localhost:3000`

---

## 2）OpenAI 兼容反代配置

### 方案 A（推荐）

- `API Base URL`：`https://your-proxy.example.com`
- `Chat API Path`：`/v1/chat/completions`
- `Models API Path`：`/v1/models`

### 方案 B（完整 URL）

- `API Base URL`：留空
- `Chat API Path`：`https://your-proxy.example.com/v1/chat/completions`
- `Models API Path`：`https://your-proxy.example.com/v1/models`

---

## 3）双提示词系统（可编辑）

- `System Prompt`：系统级约束。
- `Assistant Prompt`：assistant 预设提示词。

发送时顺序：
1. system
2. assistant prompt
3. 历史消息

---

## 4）流式传输系统

勾选“使用流式传输”后：

- 前端请求 `/api/chat/stream`
- 后端转发上游 `stream: true`
- 后端以 SSE 回传事件：
  - `token`：增量文本
  - `done`：最终文本

如果要“第 X 个不同结果”，前端会自动走非流式并请求 `n=X`。

---

## 5）SillyTavern 正则兼容（重点）

页面中的 **SillyTavern 正则规则** 支持以下格式（可多行）：

1. `/pattern/flags=>replacement`
2. `s/pattern/replacement/flags`
3. JSON 数组（每项支持 `findRegex|pattern` + `replaceString|replace` + `flags`）

示例：

```text
/<think>[\s\S]*?<\/think>/gi=>
s/<analysis>[\s\S]*?<\/analysis>//gi
```

该规则会在 **assistant 显示阶段** 顺序执行替换，用于隐藏内部标签内容或清洗格式。

---

## 6）上下文导入 / 导出

- 点击“导出上下文”可下载 JSON。
- 点击“导入上下文”可导入 JSON，恢复配置 + 历史消息。
- 导入时会做字段白名单过滤，避免异常字段污染状态。

---

## 7）重新生成 + 第 X 个结果

- “重新生成”会删除最后一条 assistant 消息并基于当前上下文再请求一次。
- 你可以设置 “第 X 个不同结果”：
  - 前端请求时携带 `n=X`、`choiceIndex=X`
  - 后端从 `choices[X-1]` 中选择结果返回（若不存在则回退到第 1 个）

---

## 8）模型列表获取

点击“获取反代模型列表”，前端会调用 `/api/models`，后端转发上游模型接口，并把 `data[].id` 填充到模型候选。

---

## 9）后端控制台日志

后端会打印：

- 请求类型（流式/非流式/模型列表）
- 上游 endpoint
- 模型、上下文大小、`n`、`choiceIndex`
- 返回摘要（preview）
- 错误信息

用于排查“看不见返回信息”的问题。

---

## 10）assistant 在哪个文件夹改

`public/app.js`

- 默认值：`state.assistantPrompt`
- 注入：`buildApiMessages()`
- 手动插入：`insertAssistantMessageManually()`
