# Proxy Chat Studio 使用文档

## 1）运行

```bash
npm install
npm start
```

访问：`http://localhost:3000`

---

## 2）OpenAI 兼容反代配置

- `API Base URL` + 相对 path（推荐）
- 或直接在 path 填完整 URL

---

## 3）SillyTavern 正则兼容（已修复）

规则输入支持以下格式（可多行）：

1. `/pattern/flags=>replacement`
2. `s/pattern/replacement/flags`
3. JSON 数组规则
4. **纯 regex 行**（无 `/.../`），默认按 `gi` 全局删除匹配文本

例如你截图中的写法（无分隔符）现在也能生效：

```text
<(thinking)>[\s\S]*?<\/(thinking)>
```

推荐更稳妥写法：

```text
<thinking>[\s\S]*?<\/thinking>
```

---

## 4）重新生成第 X 个结果（位置说明）

- 在**最后一条 assistant 气泡左下角**，有：
  - 数字输入框（X）
  - `生成第X个结果` 按钮
- 点击后会删除该 assistant，并按 `n=X, choiceIndex=X` 重新请求。
- 若上游没有第 X 个候选，会自动回退第 1 个。

---

## 5）上下文导入 / 导出

- 导出：下载 JSON
- 导入：恢复配置和历史消息（白名单字段）

---

## 6）保持简约

本版本已移除侧边栏重复的“重新生成/第X结果”控制，避免按钮堆叠，保留最直接的气泡内操作。
