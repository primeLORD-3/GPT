# Proxy Chat Studio 使用文档

## 1）运行

```bash
npm install
npm start
```

访问：`http://localhost:3000`

---

## 2）OpenAI 兼容反代配置

### 方案 A（推荐）

- `API Base URL`：`https://your-proxy.example.com`
- `Chat API Path`：`/v1/chat/completions`
- `Models API Path`：`/v1/models`

### 方案 B（完整 URL）

- `API Base URL`：留空
- `Chat API Path`：`https://your-proxy.example.com/v1/chat/completions`
- `Models API Path`：`https://your-proxy.example.com/v1/models`

---

## 3）双提示词系统（可编辑）

- `System Prompt`：系统级约束。
- `Assistant Prompt`：assistant 预设提示词。

发送时顺序：
1. system
2. assistant prompt
3. 历史消息

---

## 4）流式传输系统

勾选“使用流式传输”后：

- 前端请求 `/api/chat/stream`
- 后端转发上游 `stream: true`
- 后端以 SSE 事件回传：
  - `token`：增量文本
  - `done`：最终文本和上下文字节数

不勾选则走普通 `/api/chat`。

---

## 5）标签正则系统（`< >` 控制呈现）

你可以让模型输出标签，例如：

```text
<think>中间推理</think><final>给用户看的答案</final>
```

前端会按“隐藏标签正则（按标签名匹配）”处理：

- 命中正则的标签内容会隐藏。
- 未命中的标签会去掉标签外壳并显示内部文本。

例如正则设为：`think|analysis|internal`，则 `<think>...</think>` 会隐藏。

---

## 6）模型列表获取

点击“获取反代模型列表”，前端会调用 `/api/models`，后端转发到上游模型接口，并把 `data[].id` 填充到模型候选。

---

## 7）后端控制台日志

后端会打印：

- 请求类型（流式/非流式/模型列表）
- 上游 endpoint
- 模型、上下文大小
- 返回摘要（preview）
- 错误信息

用于解决“控制台看不见返回信息”的问题。

---

## 8）assistant 在哪个文件夹改

`public/app.js`

- 默认值：`state.assistantPrompt`
- 注入：`buildApiMessages()`
- 手动插入：`insertAssistantMessageManually()`
