# Proxy Chat Studio 使用文档

## 1. 运行

```bash
npm install
npm start
```

访问：`http://localhost:3000`

---

## 2. 配置反代（OpenAI 兼容）

### 方案 A（推荐）

- `API Base URL`：`https://your-proxy.example.com`
- `Chat API Path`：`/v1/chat/completions`
- `Models API Path`：`/v1/models`

### 方案 B（完整 URL）

- `API Base URL`：留空
- `Chat API Path`：`https://your-proxy.example.com/v1/chat/completions`
- `Models API Path`：`https://your-proxy.example.com/v1/models`

> 这两种方案二选一。

---

## 3. 两套提示词（你提的需求）

- `System Prompt`：系统级约束。
- `Assistant Prompt`：预置 assistant 消息（可编辑）。

发送时会按顺序注入：
1. system 提示词
2. assistant 提示词
3. 历史对话

---

## 4. 获取模型列表

点击 **“获取反代模型列表”** 按钮，前端会调用 `/api/models`，从上游 `Models API Path` 拉取 `data[].id` 并填充到 Model 输入候选。

---

## 5. 常见报错

### 报错：上游返回了非 JSON 数据

表示上游没返回 OpenAI JSON，多数是地址错误/鉴权错误导致命中 HTML 页面。

检查：
1. Chat API Path 是否正确。
2. API Key 是否有效。
3. 反代是否真兼容 OpenAI 返回格式。

### 报错：模型列表接口返回了非 JSON 数据

表示 `Models API Path` 配置有误或网关没返回 JSON。

---

## 6. assistant 在哪个文件夹改？

`public/app.js`。

- 默认 assistant 提示词：`state.assistantPrompt`
- 发送时注入：`buildApiMessages()`
- 手动插入 assistant 消息：`insertAssistantMessageManually()`
